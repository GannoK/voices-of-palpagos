# Contributing

The project is currently validating its runtime boundary. External issue reports are welcome; source contributions are not yet being accepted.

A useful report includes:

1. Palworld build.
2. UE4SS build.
3. Probe version.
4. Single player, listen host, dedicated server, or client.
5. Exact reproduction steps.
6. Expected and observed behavior.
7. The smallest relevant sanitized log excerpt.
8. Teardown result.

Do not upload save files, complete crash dumps, account identifiers, personal filesystem paths, credentials, or unlicensed audio.

Reports should distinguish measured behavior from inference. Runtime observations should use narrow, repeatable tests and must not modify save data.
